## About

Practice problems focused on strengthening JavaScript problem-solving skills for technical interviews. The main goal was to learn how to:

- Manipulate arrays and objects with native JS methods
- Work with strings (reversing, casing, anagram detection, palindrome checks)
- Implement sorting and searching logic from scratch
- Break down real-world-style problems
- Write clean, readable functions with clear single responsibilities

## Usage

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/martinapapp/<repo-name>.git
   ```
2. Navigate into the project folder:
   ```bash
   cd <repo-name>
   ```
3. Open any `.js` file in your editor and run it with Node.js:
   ```bash
   node <filename>.js
   ```

> No dependencies or build tools needed — these are plain JavaScript files.

## Development

### Pre-Requisites

- A text editor (VS Code recommended)
- Node.js installed (to run files locally)
- Basic understanding of JavaScript ES6+

### Build

No build process required. Each file is a self-contained JavaScript function. Open a file, read the problem description in the comments, and run it directly with Node or paste it into a browser console to test.
